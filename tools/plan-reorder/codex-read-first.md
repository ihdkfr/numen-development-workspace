# Read first: how this plan works

This is the whole Soul Survival plan, in the order you build it. Finish one phase, then start the next.

## The 14 phases
1. **Set up and check what you have.** Save everything to GitHub and play what's already built. Start here: T01.01.
2. **Decide the big things.** Answer the big questions on paper first.
3. **Build the maps.** Hueco Mundo, then Soul Society, then Karakura.
4. **Player basics.** Saving, items, money, missions, dying, parties.
5. **Movement and spiritual power.** Shunpo, Airwalk, release and pressure.
6. **Combat.** Hits, blocks, the four Shinigami arts, gear, loot and bosses.
7. **Characters and models.** Hollow designs, then every model in Blender.
8. **Animation and VFX.** The Cero's last jobs, the other beams, Kido and cutscenes.
9. **Powers.** Zanpakuto 11 to 100, Shikai, Bankai, Inner Worlds and Hollow moves.
10. **Story and life.** The Soul Reaper path and the Hollow path, start to end.
11. **Multiplayer and living world.** Trading, groups, raids, events and ranked.
12. **Look, sound and menus.** Menus, character creator, music and the store page.
13. **Launch.** Speed, safety, the shop, Roblox's rules, a closed test, then everyone.
14. **After launch.** Quincy, Fullbringer, homes and later stories. Not estimated.

Each phase has a **gate**: the check that says the phase is finished.

## Status words
| Status | What it means |
|---|---|
| To do | Not started |
| In progress | Someone is working on it |
| Needs review | Built or handed in, waiting for you to play it. Every "Check what's built" task starts here |
| Approved / done | You played it and approved it. Done means played |
| Blocked | Waiting on something, or on hold |

## Sessions and time
A **session** is one sitting with Claude Code, about 1 to 3 hours. Each task shows "about X sessions (Y if it gets tricky)". The plan assumes 7 sessions a week. When you finish a task, type how many sessions it really took into **Actual sessions**. The dashboard compares that with the estimate so the guesses get better.

## Using the Claude brief
1. Open a task and press **Copy Claude build brief**. It holds the task, its steps, the done check, the owner decisions, the full technical detail and the session rules.
2. Paste it into Claude Code in the game folder. One task per session.
3. Add Claude Code's report as a note, attach pictures or videos under Completed work, then press **Submit for review**.
4. You play it and approve it, or send it back.

Every step on a task has a **Show me how** drop-down with click-by-click instructions. If a word is new, look it up in **Words explained**. If you've never opened Claude Code or Studio for this game before, read **How to: the basics** first.

Each task's technical detail is under **Extra detail (for Claude Code)**, closed by default. You don't need to read it; the brief carries it.
