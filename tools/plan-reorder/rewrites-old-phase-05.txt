S05.01 | Check what's built: combat
W: Combat systems are already in the game. They only count as done when you have played them and they work.
1. Open Studio with the current build (see S01.01).
2. Play each item in the checklist.
3. Read the Output window after each one.
4. Write anything broken in a note here, or as a new task.
5. Approve this task when everything works.
D: Every item has been played, and it is approved or its problems are written in a note.

S05.02 | Polish basic attacks and blocking
W: Check and improve the basic fighting everyone shares: light attacks (M1), heavy hits, blocks, grabs, knock-ups and recovery.
1. Test every basic move as it is now.
2. Fix timings that feel wrong.
3. Keep the server in charge of hits.
4. Don't rewrite parts that already work.
5. Test it with lag.
D: A fight with lag still feels clear and fair.

S05.03 | Build the four Shinigami fighting arts
W: Join sword, hand-to-hand, speed movement and Kido spells (Zanjutsu, Hakuda, Hohō and Kidō) into one Shinigami fighting style.
1. Build the sword core.
2. Add hand-to-hand moves.
3. Add Hohō movement.
4. Add the Kido spellbook, chanting and healing.
5. Make Shikai add to these, not replace them.
D: A Shinigami can fight with all four arts, and Shikai adds to them.

S05.11 | Make combat work on controller and phone
W: Make the whole fighting system easy to use on a controller and a phone, not just a keyboard.
1. Check for button clashes on controller.
2. Build a phone ability tray that changes with the fight.
3. Add Bankai touch gestures.
4. Add lock-on, block and jump buttons for touch.
5. Keep timings the same everywhere.
D: A full fight works on controller and phone with nothing important hidden.

S05.12 | Build skill trees
W: Design skill trees where players pick a fighting role (weapon, hands, speed, spells or support). It shouldn't just be raw damage.
1. Check the stat and skill systems that exist.
2. Pick a few clear fighting roles.
3. Make levels unlock new options, not just bigger numbers.
4. Keep race and power more important than stats.
D: Two players with the same power can build them differently and both are fine.
