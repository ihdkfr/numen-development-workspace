S04.01 | Check what's built: spiritual power and movement
W: Spiritual power and movement systems are already in the game. They only count as done when you have played them and they work.
1. Open the current build in Studio (see S01.01).
   - Read the note on S01.01 that says which build is the current one.
   - If you're not sure, open Claude Code in the game folder and type: "Which branch is the current build and how do I open it? Don't change anything."
   - Open the game in Studio with Rojo connected (see "How to: the basics" in the Codex).
2. Play each item in the checklist, one at a time.
   - Press Play (F5) and try the first item, for example the Focus meter filling from 0 to 100.
   - If you don't know how to trigger an item, type to Claude Code: "How do I test the Airwalk V2 in Play mode? Don't change anything."
   - Do the same for Shunpo, the pressure ring and the pressure atmosphere, then press Stop.
3. Read the Output window after each one.
   - Open View > Output while the game is playing.
   - Look for red lines. Copy any red text into a note with the item's name.
   - If Output is clean and the item worked, tick that item on the checklist.
4. Write anything broken in a note here.
   - Write what you did, what went wrong and the red Output text in Notes, then press Save note.
   - For a bigger problem, type to Claude Code: "Write a short bug report for this problem. Don't change anything." Paste its report into a note.
5. Approve this task when everything works.
   - Check every checklist item has been played and ticked.
   - If all of them work, set this task's status to Approved / done.
   - If something failed, leave it in Needs review and make sure your note lists every problem.
D: Every item has been played, and it is approved or its problems are written in a note.
