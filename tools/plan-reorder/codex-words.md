# Words explained

Short, plain meanings for words that come up in the plan.

| Word | What it means |
|---|---|
| Session | One sitting with Claude Code, about 1 to 3 hours |
| Gate | The check that says a phase is finished |
| Brief | The text you copy from a task and paste into Claude Code |
| Studio | Roblox Studio, the program you build and test the game in |
| Place | One game world inside a Roblox game. Hueco Mundo is its own place |
| Realm | A world in the story: Karakura, Soul Society, Hueco Mundo, Las Noches |
| Rojo | A tool that copies code from your PC folder into Studio |
| Lune | A tool that runs the game's tests and scripts outside Studio |
| Studio MCP | The link that lets Claude Code look at and control Studio |
| Blender | Free 3D modelling program used for the models |
| Blender MCP | The link that lets Claude Code control Blender |
| Repo | The project folder that git keeps track of |
| Branch | A separate copy of the code where you try changes safely |
| Commit | Saving a snapshot of your changes in git, with a message |
| Push | Uploading your commits to GitHub |
| Pull | Downloading the latest commits from GitHub |
| Merge | Joining one branch's changes into another |
| Pull request | A page on GitHub asking to merge a branch, so you can check it first |
| Supabase | The online database that stores NUMEN's team notes and statuses |
| VFX | Visual effects: beams, flashes, smoke, sparks |
| Capture | A screenshot or video taken in Studio to prove something works |
| Render | A picture made by a program, not taken in game |
| Bake | Building something once and saving it, so the game doesn't rebuild it every time |
| Streaming | Loading the map in pieces near the player instead of all at once |
| Rig | The hidden skeleton inside a model that makes it move |
| Mesh | The 3D shape of a model |
| Triangles (tris) | The tiny flat pieces a mesh is made of. Fewer runs faster |
| Texture | The picture painted on a model, like wood or stone |
| Frame rate (fps) | How many pictures a second the game shows. Higher is smoother |
| Server | The Roblox computer running the game for everyone in it. It has the final say |
| Output | The Studio window that shows errors and messages |
| Locked | Finished and frozen. Not changed unless Usman says so |
| Placeholder | A temporary stand-in, like a grey box or a beep sound |
| HUD | The bars, buttons and numbers on screen during play |
| PvP | Player versus player fighting |
| NPC | A character the computer controls |
