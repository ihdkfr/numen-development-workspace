W: Before building lots of models, check one test bone plate goes from Blender (the 3D modelling tool) into Studio and sticks to a bone.
1. Ask Claude Code to make one test plate in Blender with a script.
   - Open Blender first and check the Blender MCP add-on says it's connected.
   - Open Claude Code in the game folder and paste this task's Claude build brief.
   - Type: "Do step 1 only: make one test bone plate in Blender with a script. Then stop and report."
   - You should see the plate appear in the Blender window.

   - Type: "Do step 2 only: export the test plate for Studio. Tell me the file name and where it is. Then stop."
   - Check its report names one file and its folder.
3. Bring it into Studio with RBXMonkey (the import tool).
   - Open the game in Studio with Rojo connected (see "How to: the basics" in the Codex).
   - Type: "Tell me exactly how to bring this plate into Studio with RBXMonkey, click by click. Don't change anything."
   - Follow its steps yourself. You should see the plate in the Explorer and in the 3D view.

   - Type: "Do step 4 only: weld the test plate to one bone in Studio. Then stop and report which bone."
   - Press Play (F5) and watch the plate. It should move with the bone, not float or fall off.
   - Open View > Output and look for red lines. Press Stop.
   - Take a capture, attach it with + Attach result and write pass or fail in Notes.
D: The test plate shows in Studio and moves with the bone.
