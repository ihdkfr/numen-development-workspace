S03.01 | Check Blender can send models to Studio
W: Before building lots of models, check one test bone plate goes from Blender (the 3D modelling tool) into Studio and sticks to a bone.
1. Make one test plate in Blender with a script.
2. Export it.
3. Bring it into Studio with RBXMonkey (the import tool).
4. Weld it to a bone and test it moves.
D: The test plate shows in Studio and moves with the bone.

S03.02 | Check what's built: models waiting for upload
W: Some models and animations are made but not in the game yet. Only you can import or upload them.
1. Import or upload each item in the checklist.
2. Play each one in Studio.
3. Read the Output window after each one.
4. Write anything broken in a note here.
D: Every item is uploaded and played, and it is approved or its problems are written in a note.

S03.03 | Make rough 3D shapes from the sheets
W: Turn the front, side and back of each design sheet into a rough 3D shape (a blockout) to check the outline. Try Kaijin first.
1. Make a blockout of Kaijin first.
2. Check if one clean-up makes it good enough.
3. Make blockouts of the other sheets.
4. Compare each outline to its sheet.
D: Every sheet has a rough 3D shape and the outlines match.

S03.04 | Build the shared Hollow body
W: Build one dark humanoid body that every Hollow uses, with bone plates added on top separately.
1. Write the brief from the art guide.
2. Make a rough shape in Tripo.
3. Clean the mesh with Instant Meshes.
4. Rig it with Rigify (add bones).
5. Paint the weights so it bends nicely.
D: The body loads in Studio, bends cleanly and stays under 9,000 triangles.

S03.05 | Build the bone plate kit
W: Write Blender scripts that make bone plates, spines, masks, claws, tails and wings that can be reused on every Hollow.
1. Make a plate script with settings for shape and thickness.
2. Make spine, mask, claw and tail scripts.
3. Make a wing script.
4. Export each piece.
5. Weld them onto the body in Studio.
D: Every kit piece shows in Studio stuck to the body, each under 2,000 triangles.

S03.10 | Set up the model checks
W: The checks every model must pass: matches its sheet from four sides, right plates, four colours only, few enough triangles, no clipping.
1. Take pictures from front, side, back and three-quarter.
2. Put them beside the design sheet.
3. Check the outline from far away.
4. Check colours and triangle count.
5. Check it walks, runs and casts without clipping.
D: Each model has a check page and you can see if it passes.
