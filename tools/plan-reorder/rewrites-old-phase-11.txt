S11.01 | Check what's built: menus, sound and looks
W: Some menus, sounds and visual polish are already in the game. They only count as done when you have played them and they work.
1. Open Studio with the current build (see S01.01).
   - Open Claude Code in the game folder (see "How to: the basics" in the Codex).
   - Type: "Which branch has the current build from S01.01, and how do I open it in Studio with Rojo? Don't change anything."
   - Open the game in Studio with Rojo connected, the way Claude Code told you.
2. Play each item in the checklist.
   - Press Play (F5) and look at the anime HUD: the on-screen bars and buttons.
   - Try the realm lighting, photo mode and the device quality settings (called device tiers in the checklist).
   - Open the DevPanel: check it is one panel, you can drag it, and the QUICK buttons work.
   - Press Stop when you have tried each item.
3. Read the Output window after each one.
   - Open View > Output before you press Play.
   - After each item, look for red lines in Output.
   - If you see red text, copy it into a note on this task with the item's name.
4. Write anything broken in a note here, or as a new task.
   - For each problem, write what you did, what you expected and what happened.
   - Press Save note. For a big problem, ask Claude Code to help you word it as a new task.
5. Approve this task when everything works.
   - Tick each checklist item that worked with no red lines in Output.
   - If every item is ticked, press Submit for review. If not, leave it open and keep the notes.
D: Every item has been played, and it is approved or its problems are written in a note.
